# Code of Conduct

We want Browser Kitten to be a useful, welcoming place to collaborate. These expectations apply to issues, pull requests, reviews, and other project spaces, regardless of a person's background, identity, or level of experience.

- Be respectful, patient, and specific. Critique ideas and code rather than people.
- Welcome questions, different perspectives, and good-faith corrections.
- Respect privacy. Do not publish another person's credentials, private communications, or identifying information without permission.
- Do not harass, threaten, discriminate, use sexualized language or imagery, or repeatedly disrupt discussions. Spam and personal attacks are not welcome.

Maintainers may edit or remove inappropriate content, close disruptive discussions, or restrict participation. They should explain moderation decisions when doing so does not expose private information or cause further harm.

For conduct concerns, contact [@Player-YN](https://github.com/Player-YN) through a private contact method listed on their profile. If none is available, ask for a private contact channel without posting the incident or personal details publicly. This project does not promise a fixed response time.

**中文：**请友善、具体地讨论问题，尊重他人隐私，不进行骚扰、歧视、人身攻击或刷屏。行为问题可通过维护者个人主页提供的私密联系方式反馈；没有私密入口时，可先请求联系方式，不要公开当事人的隐私。
