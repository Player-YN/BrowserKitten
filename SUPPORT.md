## Ask or report

Search [existing issues](https://github.com/Player-YN/BrowserKitten/issues). If your problem is new, use the [bug report form](https://github.com/Player-YN/BrowserKitten/issues/new?template=bug_report.yml); for a capability proposal, use [feature requests](https://github.com/Player-YN/BrowserKitten/issues/new?template=feature_request.yml). Other questions can use a blank issue. Chinese and English are welcome.

Include the extension/source version, Chrome version, operating system, a small reproduction, and the exact error. A redacted screenshot can help. Never post keys, tokens, cookies, or entire private conversation exports. Screenshots and task traces can contain sensitive page content even when no key is visible.

Suspected vulnerabilities belong in [private security reporting](SECURITY.md). For model-provider billing, quotas, or service availability, contact that provider. Browser Kitten account-hosted services depend on a separate backend.

This is a community project with no guaranteed response time or support SLA.
