# Changelog

Notable user-facing changes are recorded here. `main` may be ahead of tagged GitHub releases; the current manifest version is **1.2.0**. An unreleased entry does not announce a published release.

## [Unreleased]

### Added

- Local ongoing-task observations, change-aware reporting, configurable stop conditions, and per-round budgets.
- Autonomous scheduling and removal of follow-ups within the authorized goal.
- English and Chinese project homepages, setup guides, documentation navigation, and community contribution/reporting files.

### Changed

- Recoverable tasks live in a collapsible drawer above the composer instead of the top of the chat.
- The fixed Agent personality is English and separate from runtime execution contracts.
- Distribution instructions distinguish Inference and System1 setup; packages include third-party notices.

### Fixed

- System1's settings probe uses the same chat endpoint and decision format as the page executor.
